# Optional: Try It in Real RStudio

These are **optional**. They're the real test of whether the course transfers to your own computer, so if you have the time, they're the most useful thing you can do. Do each one in **real RStudio on your own computer** (not inside the course), at the point listed. Don't spend more than about 15 minutes stuck on any one; if you get stuck, note where and move on.

There's nothing to write up here beyond a line or two. Jot notes wherever is easiest, and mention anything important on the one-page feedback form.

---

## Checkpoint 1: after Module 3 ("Data")

**File:** `checkpoint1_seedling_heights.csv`

1. Save the file somewhere you can find it, and make that folder your working directory (or open an RStudio Project there).
2. Read the file into R and look at it.
3. How many rows and columns does it have? What type is `height_cm`? What are the two values in `treatment`?

## Checkpoint 2: after Module 4 ("Clean up")

**File:** `checkpoint2_bird_counts_messy.csv` (intentionally messy, like real data)

1. Read it in and clean up the column names.
2. Make a table of the average bird `Count` at each site, **ignoring missing counts** (not treating them as zero), sorted highest to lowest.
3. Keep the code you used.

## Checkpoint 3: after Module 5 ("Plots")

1. Find any spreadsheet or CSV of your own (anything at all).
2. Import it, check how many rows and columns it has and what type each column is, and make one plot of anything.
3. Note anything about your file that the course didn't prepare you for.

## Checkpoint 4: after Module 6 (capstone preview)

**Files (same folder):** `capstone_model_comparison.R` and `capstone_fish_survey.csv`

1. Open the script in RStudio and work through it top to bottom, filling in each `FIXME` (the comment above each one says what goes there) and running each step as you go.
2. It may install one extra package the first time; that's expected.
3. Answer the five questions at the bottom of the script in your own words.
